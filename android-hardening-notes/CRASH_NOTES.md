# کرش و صفحه‌سیاه بعد از حذف/نصب مجدد

## نمی‌تونم بدون لاگ مطمئن باشم، ولی محتمل‌ترین علت

`AndroidManifest.xml` (که خود Capacitor موقع `cap add android` می‌سازه)
داره `android:allowBackup="true"` می‌ذاره. این یعنی اندروید به‌صورت
خودکار داده‌ی اپ (که شامل حافظه‌ی داخلی WebView هم می‌شه — یعنی همون
جایی که `localStorage` اپ توش ذخیره می‌شه) رو قبل از حذف بک‌آپ می‌گیره،
و موقع نصب دوباره برش می‌گردونه.

توی یه پروژه که هنوز داره سریع تغییر می‌کنه (نسخه‌های پشت‌سرهم build
می‌شن)، این یعنی: نصب جدید ممکنه با یه `localStorage` قدیمی/ناسازگار
(مال build قبلی) بالا بیاد، و اگه شکل داده‌ها فرق کرده باشه، کد جاوااسکریپت
موقع خوندنش خطا بده → صفحه‌سیاه یا کرش.

## راه‌حل (برای فاز توسعه — بعداً قبل از انتشار نهایی تصمیم جدا می‌گیریم)

توی `android/app/src/main/AndroidManifest.xml`، این خط:
```xml
android:allowBackup="true"
```
رو موقتاً به این تغییر بدید:
```xml
android:allowBackup="false"
```

این کار هر بار uninstall/reinstall رو تضمین می‌کنه که کاملاً از صفر
شروع بشه — بدون داده‌ی قدیمی باقی‌مونده.

## برای تشخیص قطعی کرش «app stopped»

بدون لاگ نمی‌شه صد در صد مطمئن شد. اگه بعد از این تغییر بازم کرش کرد،
لطفاً دقیقاً بگید چه کاری داشتید می‌کردید لحظه‌ی کرش (کدوم صفحه، چه
عملی) — این کمک می‌کنه دامنه‌ی احتمالی رو محدود کنیم حتی بدون لاگ خام.
